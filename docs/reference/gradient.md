# 渐变（轴向 / 线段 / 折线）

> 面向 vireo 使用者。目标读者：想在**一个形状内部**做平滑颜色/透明度过渡的人。
> 适用版本：0.2.0。
>
> 相关：[折线逐点色](line-gradient.md)（`draw_line_chain_colors`，逐点给色的另一条用法）。

## 1. 三种形状，三个"渐变坐标"

渐变坐标**由形状决定**，不由调用方选 —— 这样每次调用都不需要想"轴该从哪到哪"：

| 形状 | 坐标 | 说明 |
|---|---|---|
| 线段（`Shape::Line`） | 沿 `p1 → p2`，`0` = p1、`1` = p2 | `draw_line_gradient` **没有角度参数** |
| 折线（`Shape::LineChain`） | 沿**弧长** | 点距不均匀也均匀过渡 |
| 其余（矩形/圆角矩形/圆/椭圆/三角形/多边形/弧） | 沿 `angle_deg`，且**跨满形状包围盒** | 不需要给端点，永远不会"轴短了" |

"跨满形状"的意思是：渐变自动把形状的包围盒投影到渐变轴上，`at = 0` 落在最靠"起点"的
边上、`at = 1` 落在对面那条边上。想只渐变底部 38%？用停点位置表达，见 §3。

## 2. 基本用法

```rust
use vireo::prelude::*;

// 压暗：底部 38% 内 0 → 0.62，上面保持透明（"平台 + 淡出"用停点位置表达）
let scrim = [
    GradientStop::new(0.0,  Color::new(0.0, 0.0, 0.0, 0.0)),
    GradientStop::new(0.62, Color::new(0.0, 0.0, 0.0, 0.0)),
    GradientStop::new(1.0,  Color::new(0.0, 0.0, 0.0, 0.62)),
];
draw_rect_gradient(&mut batch, Pos::new(x, y), 448.0, 252.0, LinearGradient::vertical(&scrim));

// 圆角矩形（渐变不会越过圆角）
draw_rounded_rect_gradient(&mut batch, pos, w, h, 24.0, LinearGradient::vertical(&scrim));

// 圆：轴向跨越直径（不是径向渐变）
draw_circle_gradient(&mut batch, Pos::new(cx, cy), 40.0, LinearGradient::vertical(&[
    GradientStop::new(0.0, WHITE),
    GradientStop::new(1.0, Color::new(0.2, 0.3, 0.9, 0.0)),
]));

// 线段：沿走向，无需角度
draw_line_gradient(&mut batch, 40.0, 300.0, 680.0, 300.0, 12.0, &[
    GradientStop::new(0.0, Color::new(1.0, 0.85, 0.3, 1.0)),
    GradientStop::new(1.0, Color::new(0.2, 0.85, 0.95, 1.0)),
]);

// 任意形状（含折线、多边形、三角形、弧）
draw_shape_gradient(&mut batch, &Shape::Polygon { points: &pts }, LinearGradient::at(35.0, &stops));
```

`DrawBatch` 上也有同名镜像方法：`b.rect_gradient(..)` / `b.rounded_rect_gradient(..)` /
`b.circle_gradient(..)` / `b.line_gradient(..)` / `b.shape_gradient(..)`。

角度约定：单位是**度**，屏幕坐标系（y 向下）顺时针 —— `0` = 自上而下，`90` = 自左而右，
`180` = 自下而上。也可以用 `LinearGradient { angle_deg, stops }` 直接构造。

## 3. 停点规则

`GradientStop { at, color }`，`at` 是沿渐变坐标的**归一化**位置：

| 写法 | 效果 |
|---|---|
| `(0, a), (1, b)` | 普通线性过渡 |
| `(0, a), (0.62, a), (1, b)` | 前 62% 平台，后 38% 淡出（vault 的压暗就是这个） |
| `(0, a), (0.5, a), (0.5, b), (1, b)` | 0.5 处**硬边** |
| `at < 0` 或 `at > 1` | 越界部分被钳制，等价于多加一个平台 |
| 乱序的 `at` | 编码时按 `at` 稳定排序，**顺序无关** |
| 同一 `at` 两个停点 | 硬边（后写的那个赢） |

另外：**颜色在预乘空间插值**（红 a=0.9 → 蓝 a=0 的中点是无偏的红，不会混出紫色），
所以「透明 → 深色」这种压暗渐变不会出现边缘发暗。

## 4. 只走 SDF 路径（重要）

渐变**只存在于 SDF 实例路径**。用上面任何一个 API 绘制时：

- 会**强制**走 SDF 实例（即使当前 batch 在几何模式：`clear_sdf_feather()` 之后）；
- `sdf_feather` 只决定边缘软硬 —— 几何模式下等于羽化 `0`（**硬边**，没有抗锯齿过渡）；
- **不存在"静默变成单色"**：要么画出渐变，要么（停点退化时）画出等价的单色。

代价：多边形在 SDF 路径上要逐像素做边测试；如果某次绘制本来走几何模板是为了省这个开销，
用渐变会让它切回 SDF。这是渐变要逐像素取色的本质，不是实现选择。

**不支持**：geo 模板路径与 mesh 顶点路径（前者顶点没有颜色通道、实例也没有空位，
后者直通空间插值会在"彩色→透明"出暗边，且内置形状在几何模式下并不走 mesh）、
自定义材质（色带由引擎片元读取）、文字（`local_pos` 对字形无意义）。

## 5. 降级与边界（都不 panic）

| 输入 | 行为 |
|---|---|
| 没有有效停点 | 不画 |
| 1 个停点 / 所有停点同色 | 退化为普通单色绘制，**与不带渐变的路径逐像素一致** |
| 所有停点 alpha = 0 | 不画 |
| `at` 或颜色分量 NaN/∞ | 该停点被丢弃 |
| 形状尺寸 ≤ 0 | 与单色路径**同一行为**（不多画也不少画） |
| 沿轴跨度为 0 | 整形状取渐变中点色（不产生 NaN） |
| `angle_deg` NaN/∞ | 当 0（自上而下） |
| 圆角半径越界/负/NaN | 钳到 `[0, min(w,h)/2]`（与单色圆角矩形一致） |
| 自定义顶点着色器不支持 SDF 实例布局 | 按既有规则跳过并 warn-once |

## 6. 性能

- **一个形状 = 一个实例 = 一次 draw**，与单色绘制完全相同（不多一个 batch、不多一个 bind group）。
- 渐变坐标在**顶点着色器**里算一次（kind 0）或复用 case 内已算好的量（线段/折线），
  **片元零额外求值**；每像素只多一次色带查表（2~5 个停点的线性扫描）。
- 色带按**内容**去重：同停点、同角度 → 同一份数据（与形状尺寸、位置无关）。所以一屏
  同样的卡片压暗只占 1 条色带。角度是色带身份的一部分（不同角度 = 不同色带）。
- 与「切 N 条窄带」相比：vault 那 6 张卡 78 个 quad / 13 层 blend → **12 个实例 / 1 段**。

## 7. 实测数据

`tests/gpu_bench.rs`（离屏 canvas 是 **sRGB** 目标）：

| 用例 | 结果 |
|---|---|
| 8 种形状（矩形/圆角/圆/椭圆/线/三角/多边形/弧）单色渐变 vs 单色绘制 | **逐像素一致** |
| 竖直 2 色渐变（80px） | 线性空间与理想 ramp 最大偏差 **≤ 4.3/255**，单调、逐像素无台阶 |
| 平台 + 淡出（0/0.62/1） | 上 62% 恒定（±1/255），下段单调 |
| 角度 0° vs 90° | 轴正交、互不干扰 |
| batch 旋转 90° | 渐变随形状一起转（本地空间） |
| 圆角 20px | 角外像素 **0**，渐变不越界 |
| 透明 → 黑 叠白底 | 中点为 50% 压暗，无"边缘发暗" |
| 圆 / 折线（弧长中点）/ 线段端点 | 分别取到端点色、弧长中点色、10%/90% 混合 |
| 多边形（垂直轴） | 跨满自身包围盒、逐行单调 |
| 同 `at` 两个停点 | 硬边一跳、整列无 NaN 黑洞 |
| 线段渐变 vs 两点折线渐变 | **逐像素一致**（kind 2 ≡ kind 1） |
| 贴图 + 渐变 | 结果 = 贴图 × 渐变 |
| 退化（空/单停点/零尺寸/NaN 角度） | 不 panic，行为符合 §5 |
